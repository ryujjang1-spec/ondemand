# 온디멘드 AI콜센터 데모앱

## 실행 방법

1. ZIP 파일 압축 해제
2. VS Code에서 압축 해제한 폴더 열기
3. 터미널에서 아래 명령 실행

```bash
python -m pip install streamlit pandas
python -m streamlit run app.py
```

Python 명령이 인식되지 않으면 아래 명령을 사용하세요.

```bash
py -m pip install streamlit pandas
py -m streamlit run app.py
```

## 포함 기능

- AI 상담 시작
- 고객 전화 인입
- AI 요청 분석
- 예약 배차 제안
- 예약 완료
- 인간 상담원 이관
- 장애 대응 데모
- 관리자 대시보드
- 24시간 365일 운영비 절감 분석
